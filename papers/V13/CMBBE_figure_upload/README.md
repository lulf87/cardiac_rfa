# CMBBE Figure Upload Package

This directory contains the upload-ready original figure files for Figures 1-8 in the blinded manuscript:
`papers/V13/CMBBE_main_document_blinded_final.docx`

All figure files are provided as high-resolution PNG images, and each filename matches the figure number used in the manuscript.

## Files included

- `Figure1.png` - Reduced 2D model geometry and workflow
- `Figure2.png` - Representative spatial fields for the baseline fixed-power formulation
- `Figure3.png` - Deterministic four-way comparison across representative slices
- `Figure4.png` - Grid and time-step verification for the baseline nominal case
- `Figure5.png` - Depth-fraction maps for fixed-power and generic temperature-limited 90 W / 4 s
- `Figure6.png` - Peak-temperature maps for fixed-power and generic temperature-limited 90 W / 4 s
- `Figure7.png` - Controlled-minus-fixed difference maps for 90 W / 4 s
- `Figure8.png` - Reference literature-derived benchmark of lesion-depth trends

## Traceability

- The files in this directory were copied from `papers/V12/figure_refresh_png/`.
- Each `Figure1.png` to `Figure8.png` file is byte-identical to the corresponding image embedded in `papers/V13/CMBBE_main_document_blinded_final.docx`.
- This package is intended for journal figure upload only and does not modify the manuscript source files.
