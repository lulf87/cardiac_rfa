# REPRO_GAPS

## Scope

This file records unresolved reproducibility ambiguities found during the
repository audit. No source files were modified during this audit.

## Open gaps

### 1. Root README is stale and not authoritative

- `README.md` currently describes a `stage11_repo_benchmark` pack rather than
  the present repository layout.
- This means a reader starting from the repo root will not learn that
  `simulation/stage17_controlled_rebuild/` and
  `analysis/stage17_methodology_figs/` are the current source paths.

Candidate files:

- `README.md`
- `AGENTS.md`
- `simulation/stage17_controlled_rebuild/README.md`
